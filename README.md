# 六爻问卦

一个基于周易六爻的古法占卜网站，模拟古法掷钱成卦，为迷茫、疑惑的用户提供思考的角度。

## ✨ 功能

- **模拟古法掷钱成卦** —— 三枚铜钱、六爻问卦，还原传统占卜流程
- **AI 智能解卦** —— 接入 DeepSeek 大模型，结合用户具体问题生成个性化解读
- **64 卦完整数据** —— 每卦覆盖事业、感情、财运、健康、学业、抉择六大类别
- **卦金文化引导** —— 以「卦不空出，术不空施」的古训引导打赏
- **禁忌类问题过滤** —— 前后端双重校验，8 大类禁忌内容自动拦截

## 🛡️ 合规与安全

本站不受理以下类型的问题：
- 政治议题、生死之事、他人隐私、胎儿性别
- 股票理财、赌博博彩、鬼神灵异、违法伤人

后端做了速率限制（单 IP 每小时 5 次、每日 20 次）和 Referer 校验，防止 API 被恶意刷用。

## 🚀 部署

见 [DEPLOY.md](DEPLOY.md)。核心两步：

1. 部署到 Vercel（免费额度足够个人使用）
2. 配置环境变量 `DEEPSEEK_KEY` 和 `ALLOWED_ORIGINS`
